Paint this page with

Five mediums. One attribute.

Put data-medium on <html> to paint the whole site, or on any single element to paint just that part.

Watercolor

Translucent washes that bleed at the edges, grainy pigment and darker rims where the paint pools.

Badge
data-medium="watercolor"

Acrylic

Thick impasto in short, directional dabs of broken color, with lit ridges, a little gloss and stroke ends for edges.

Badge
data-medium="acrylic"

Charcoal

Shaky hand-drawn outlines, gritty broken lines and cross-hatching. In dark mode it turns to chalk on slate.

Badge
data-medium="charcoal"

Paper

Cut and torn construction paper, layered and taped down. Fibrous torn edges, paper grain and soft shadows.

Badge
data-medium="paper"

Marker

A few fat felt-tip strokes in one back-and-forth scribble, with rounded hairpin turns and translucent ink that darkens where it overlaps.

Badge
data-medium="marker"

Get started

No build step and no dependencies. One stylesheet and one small script.

Option 1 · CDN

Drop it in

<link rel="stylesheet"
  href="https://cdn.jsdelivr.net/gh/ghanemja/art-asset@v0.1.0/src/art-medium.css">
<script type="module"
  src="https://cdn.jsdelivr.net/gh/ghanemja/art-asset@v0.1.0/src/art-medium.js"></script>

<body class="am-canvas" data-medium="watercolor" data-theme="auto">
  <button class="am-button">Hello</button>
</body>
Option 2 · npm

Install it

npm i github:ghanemja/art-asset#v0.1.0

// in your app
import 'art-medium/css';
import { setMedium, setTheme } from 'art-medium';

setMedium(document.documentElement, 'acrylic');
setTheme(document.documentElement, 'dark');
Option 3 · React

Use the wrappers

import 'art-medium/css';
import { MediumProvider, Button, Card }
  from 'art-medium/react';

<MediumProvider medium="charcoal" theme="auto">
  <Card title="Still life">
    <Button variant="secondary">Buy</Button>
  </Card>
</MediumProvider>

Want gouache, ink wash or pastel? A medium is one block of CSS tokens plus one SVG filter. See adding a medium.
