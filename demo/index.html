Get started

Add the stylesheet and script, then put data-medium on any element.

<link rel="stylesheet" href="https://ghanemja.github.io/art-asset/src/art-medium.css">
<script type="module" src="https://ghanemja.github.io/art-asset/src/art-medium.js"></script>

<body class="am-canvas" data-medium="watercolor">
  <button class="am-button">Primary</button>
  <button class="am-button am--secondary" data-medium="acrylic">Acrylic</button>
  <article class="am-card"><h3 class="am-card__title">Still life</h3></article>
</body>

React wrappers, variants and how to add your own medium are in the README.
